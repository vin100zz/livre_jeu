# Les Enfants de Brumeval

Un livre-jeu en ligne, conte feerique ambigu dans la foret de Brumeval.
Jouable directement dans le navigateur : ouvrez `index.html`.

- `story.js`, `story2.js` : l'histoire (passages, objets, fins)
- `engine.js` : le moteur de jeu
- `outils/valider.js` : verifie les liens (`node outils/valider.js`)
