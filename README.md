# Les Enfants de Brumeval

Un livre-jeu en ligne, conte féerique ambigu dans la forêt de Brumeval.

**Jouer : https://vin100zz.github.io/livre_jeu/**

## Pour les curieux

- `story.js`, `story2.js` : l'histoire (passages, objets, fins)
- `engine.js` : le moteur de jeu
- `outils/valider.js` : vérifie les liens (`node outils/valider.js`)
